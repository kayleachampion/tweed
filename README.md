# Tweed

A Markdown-native toolkit for managing research, teaching, and advising.

## Philosophy


Tweed treats your Obsidian vault as the canonical database.

No proprietary formats.

No hidden metadata.

No lock-in.

Git is the history.

Obsidian is the interface.

Python is the automation.

Nothing is stored anywhere except your Markdown files.

Tweed provides automation.

## Features

- Create projects
- Create students
- Create meetings
- Roll courses between quarters
- Generate dashboards
- Validate vault consistency


## How To

Add a new template:
	1 - Write the template as templates/<templatename>.py
	2 - Edit the REGISTRY so the item will be recognized
